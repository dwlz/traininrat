# 💪 TraninRat – App de Registro de Atividades de Academia

**TraninRat** é um aplicativo focado em usuários de academia que desejam registrar suas atividades diárias, como calorias gastas, velocidade na esteira, tempo de treino e muito mais.

---

## 🧱 Tecnologias utilizadas

### 📱 Frontend (App)
- [React Native](https://reactnative.dev/)
- [Expo](https://expo.dev/)
- Axios (para chamadas à API)
- AsyncStorage (para armazenar token do usuário, se usar login)

### 🌐 Backend (API)
- [FastAPI](https://fastapi.tiangolo.com/)
- Uvicorn (servidor ASGI)
- SQLite (banco de dados leve)
- Pydantic (validação de dados)
